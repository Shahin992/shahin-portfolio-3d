Built the same way

  • Hand-written HTML, CSS and vanilla JavaScript, with animation from Motion (the vanilla-JS edition of Framer Motion). There's no framework and no CMS.
  • Every page works without JavaScript, and visitors who ask for reduced motion get a calm, static page.
  • Clean URLs, a noindex 404 page, sitemap.xml, robots.txt and llms.txt on every site.
  • Self-hosted WOFF2 font subsets with the critical files preloaded, and photos cropped to WebP at the sizes each layout needs.

Search is built in from the first page: canonical URLs, JSON-LD on every page, 236+ FAQ answers marked up across the eight sites, sitemap.xml, llms.txt and a robots.txt that welcomes AI search crawlers.
