Overview

SummaryCliento is a full-stack CRM web application built by Shahin Alam with React.js, TypeScript, Redux Toolkit, React Query and Material-UI on the frontend and Node.js, Express.js and MongoDB on the backend. It features JWT authentication, role- and subscription-based protected routes, Stripe subscription billing, Gmail API email threads inside the CRM, Cloudinary file uploads and Brevo email workflows.

Cliento is my end-to-end take on a modern CRM: one place to manage customers, the email conversations you have with them, and the subscription that unlocks the product. I built both halves, a typed React frontend and an Express REST API, with a focus on performance, scalability and clean architecture.

Engineering highlights

  • Server state vs. client state. React Query handles fetching and caching API data, and Redux Toolkit holds application state, so each concern stays predictable.
  • Access that follows the plan. Protected routes check both the user's role and their subscription status.
  • Four services, one product. Stripe, the Gmail API, Cloudinary and Brevo are integrated into a single, coherent workflow.
  • Modular by design. Frontend and backend are both organized into maintainable modules that follow clean-architecture principles.
  • Documented API. The backend ships with public API docs.
